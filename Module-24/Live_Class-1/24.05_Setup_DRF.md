# 🛠️Setup a DRF Project

### ▶️Visit DRF website
- For Full installation guide visit
```
https://www.django-rest-framework.org/#installation
```

------------------------------------
------------------------------------



## 1️⃣Create a Project Folder
- Create a Main Folder using a proper name
- Open that folder into `git bash`


## 2️⃣Create a Virtual Environment
- Create a Virtual Environment inside the project folder
- Activate the Virtual Environment 


-------------------


## 3️⃣ Install Necessary things
- In the guide we have the following to Install:
```bash
pip install djangorestframework
```
- Optional
```
pip install markdown                        # Markdown support for the browsable API.
pip install django-filter                   # Filtering support
```


-------------------


## 4️⃣Create Django Project
```bash
django-admin startproject project_name
```


------------


## 5️⃣ Create Django Project-App
```bash
django-admin startapp app_name
```


------------


## 6️⃣ settins.py
- Add '**rest_framework**' to your INSTALLED_APPS setting
```py
INSTALLED_APPS = [
    ...
    'rest_framework',
]
```


------------


## 7️⃣ urls.py [main project]
- This is needed for adding REST framework's login and logout views
```py
urlpatterns = [
    ...
    path('api-auth/', include('rest_framework.urls'))
]
```
