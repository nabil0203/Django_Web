- Data from the database comes as a QuerySet
    - Basically, a list of Django model instances
- To use data in an API
    - The data coming from the database must be converted into **JSON format**
    - Because frontend or clients (React/Vue) understand JSON
- This conversion is handled by a **Serializer**

---

### ▶️Inside each app we create a file named:
- `serializer.py`


---------------------



# 📌Steps

---------------------


## 1️⃣`serializer.py`

- It is as same as `forms.py`
- Insted of **forms** we need to use **serializer**
- By using it, we can directly convert data in JSON
```py
from rest_framework import serializers
from . import models


# serializers are same as the form.py

class AuthorSerializer(serializers.ModelSerializer):
    books = serializers.StringRelatedField(many=True, read_only = True)                                   # Serializer relation -> Live_Class-1__24.12
    class Meta:
        model = models.Author
        fields = '__all__'


class BookSerializer(serializers.ModelSerializer):
    class Meta:

        model = models.Book
        fields = '__all__'
```



---------------------


## 2️⃣`views.py`
```py
from .serializers import AuthorSerializer, BookSerializer

@api_view(['GET', 'POST'])
def author_list_create(request):

    # get request
    if request.method == 'GET':
        authors = Author.objects.all()

        serializer = AuthorSerializer(authors, many = True)                                 #👈 as GET request, we are fetching data from DB as a query set
                                                                                            #👈 then converting the query set into --> JSON ; here, using serializer instead of forms

        return Response(serializer.data, status=status.HTTP_200_OK)   
```
