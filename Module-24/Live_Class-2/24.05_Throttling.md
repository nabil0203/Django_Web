## ▶️What is Throttling
- Limits how many times a user can request
    - like 3 request per Minute


---------------------



## 📋Setup

### 1️⃣`settings.py`
```py
REST_FRAMEWORK = {
    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.AnonRateThrottle',
        'rest_framework.throttling.UserRateThrottle'
    ],
    'DEFAULT_THROTTLE_RATES': {
        'anon': '100/day',                                      #👈anonymous user 100 per day
        'user': '1000/day'                                      #👈Logged in user 1000 per day
    }
}
```

> Rate can be changed
- `'anon': '2/minute',`
- `'user': '10/minute`
