## 📌Two names are frequntly used in Tokens 

### 1️⃣Access Token: 
- A short-lived token 
- Used to authenticate requests 

### 2️⃣Refresh Token: 
- A longer-lived token
- Identify User as previously logged in 
- Used to obtain new access tokens when the current access token expires, without requiring the user to re-authenticate with



--------------------------------



## 📋Steps

### 1️⃣Istall inside project
```py
pip install djangorestframework-simplejwt
```


---------


### 2️⃣`settings.py`
- Inside **INSTALLED_APPS**
    - add `rest_framework` and `rest_framework_simplejwt`
```py
INSTALLED_APPS = [

    #................
    #................


    'rest_framework',
    'rest_framework_simplejwt',

    
    #................
    #................

]
```

---------



### 3️⃣`settings.py`
- Inside **REST_FRAMEWORK** add:
```py
REST_FRAMEWORK = {

    #.............
    #.............


    'DEFAULT_AUTHENTICATION_CLASSES': (
        'rest_framework_simplejwt.authentication.JWTAuthentication',
    ),


}
```


---------




### 4️⃣ `settings.py`
- Import `timedelta` for **SIMPLE_JWT**
```py
from datetime import timedelta
```



---------



### 5️⃣ `settings.py`
- Add **SIMPLE_JWT**
```py
SIMPLE_JWT = {

    'ACCESS_TOKEN_LIFETIME': timedelta(minutes=5),
    'REFRESH_TOKEN_LIFETIME': timedelta(days=1),

}
```



---------



### 6️⃣ Project `urls.py`
- Import:
```py
from rest_framework_simplejwt.views import TokenObtainPairView, TokenRefreshView
```



---------




### 7️⃣Project `urls.py`
- Inside **urlpatterns** add
```py

urlpatterns = [

    #.............
    #.............


    path('api/token/', TokenObtainPairView.as_view(), name='token_obtain_pair'),
    path('api/token/refresh/', TokenRefreshView.as_view(), name='token_refresh'),   


    #.............
    #............. 


]
```



---------



### 8️⃣`views.py`
- Import
```py
from rest_framework.permissions import IsAuthenticated
```



---------



### 9️⃣`views.py`
- Inside the **class based view** add
```py
class AuthorViewSet(viewsets.ModelViewSet):

    queryset = Author.objects.all()
    serializer_class = AuthorSerializer


    #...............
    #...............
    #...............



    permission_classes = [IsAuthenticated]                          #👈 # token authentication

```



---------



### 1️⃣0️⃣Result
- In browser **http://127.0.0.1:8000/api/authors/**
- As the user is not logged in, it will show:
```
{
    "detail": "Authentication credentials were not provided."
}
```
- Inside `views.py` if you commnet out--> `# permission_classes = [IsAuthenticated] `:
    - it will show data again

## 🎉Steps to Access Data by token:
- Copy the `Access Token`
    - Step 1️⃣1️⃣
- Inside that Request of Postman find --> **Authorization**
- Select ***Type*** ---> **Bearer Token**
- Inside the **Token** field
    - Paste the `Access Token`
- Click Send

-----------------------------------
### 🎉🎉Now the JSON Data will be shown🎉🎉
- Because this request is send by an authenticated user
