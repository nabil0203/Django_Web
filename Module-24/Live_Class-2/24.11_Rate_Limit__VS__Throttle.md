# 💥Rate Limit VS Throttle

## 📌Rate Limit
- After exceeding the number of request it Blocks the user
- Example
    - Allowing only 10 login attempts per minute from a single IP address to prevent brute-force attacks.
    - When you need strict enforcement of usage policies, such as limiting a user to 1,000 API calls per day or for security purposes.

----------------
## 📌Throttle
- Control the rate of request
    - by slowing them down
    - insted of blocking
- User Request can be Refuled
- Example
    -  When you want to prevent your system from being overloaded during peak usage times, such as during a flash sale or a product launch, while still allowing the requests to eventually process.
