# 🗑️Delete Task
- Every task will have a **Delete** button
- When clicked on delete button
    - it will delete the task from the `array`
    - then update the array into `local storage`

## `Task_Item.jsx`
```js
function Task_Item({ task, deleteTask }) {

    return (
        <div className="flex justify-between py-2 px-4 w-100 overflow-hidden border border-gray-300 rounded-md">

        //-------------------------------------------
        // -------------------------------------------
        //-------------------------------------------

            <button onClick={() => deleteTask(task.id)} className="bg-red-500 hover:bg-red-600 text-white px-3 py-1 rounded-md">
                Delete
            </button>
        </div>
    )
}

export default Task_Item
```

            setTask(updatedTasks)                                                               // updating the tasks in state  
            saveTaskToLocalStorage(updatedTasks)                                                // saving the updated tasks in local storage
        }


        // -----------------------------

        {/* Show Tasks */}
        <div className="my-6 space-y-3">
        {tasks.map((task)=>{

          return <Task_Item key={task.id} task={task} deleteTask={deleteTask} />                   // passing the deleteTask function to the Task_Item component

      </div>

}
