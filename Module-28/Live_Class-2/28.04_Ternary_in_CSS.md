# 🎛️Ternary in CSS

## 📌To add condition in CSS class
- Use **Ternary Operator**

## 📋How to use it?
- change the double quote `"` to backtick `` ` ``
- Add condition using **Ternary Operator** inside the backtick
- use **$** sign before the variable
- use curly brace `{}`
- write the **CSS class name** you want to apply based on the condition

-------------------------------------------------------------------

## 📍Example
```jsx
<div>
    <p className={`font-bold ${task.isCompleted ? 'line-through' : ''}`}> {task.title} </p>
    <p className="font-normal text-sm">{task.description}</p>
</div>
```

- "line-through" is a class name in **TailwindCSS**
- It is used to add a line-through to the element
- It is a **conditional class**
    - It is only applied when the `task.isCompleted` is true
