# 🗑️Local Storage
- This is a different functionality from `component` 
- We use a **utils** directory to store all the utility functions
- In `src` directory create one more directory named `utils`
- Inside `utils` create a file named `tasks.js`



## 1️⃣Save tasks in local storage
### `Task_Viewer.jsx`
```js
saveTaskToLocalStorage([...tasks, taskObj])
```

### `utils/tasks.js`
```js
export function saveTaskToLocalStorage(tasks){

  localStorage.setItem("tasks", JSON.stringify(tasks))

}
```
- `localStorage.setItem()` -> saves the data in local storage
- `tasks` -> name of the item (key)
- `JSON.stringify()` -> converts array/object into string
- `[...tasks, taskObj]` -> new task added with existing tasks array using spread operator

-----------------------------------------
-----------------------------------------

### ⚠️ If reload browser the data will be gone
- To fix this we need to **get** the data from local storage after the page is loaded

--------------------------------------------
--------------------------------------------


## 2️⃣Get tasks from local storage

#### `Task_Viewer.jsx`
```js
const [tasks, setTask] = useState([])
```
- Initially the state is empty array
- This is why the default parameter is `[]` in `useState`

-------------------------------------------

### ➡️ After the page is loaded
#### `Task_Viewer.jsx`
```js
const [tasks, setTask] = useState(getTasksFromLocalStorage())
```
#### `utils/tasks.js`
```js
export function getTasksFromLocalStorage(){

  return JSON.parse(localStorage.getItem("tasks")) || []

}
```
- `localStorage.getItem("tasks")` -> gets the data from local storage
- `JSON.parse()` -> converts string of tasks to an array
- `|| []` -> checks first local storage have any data or not if not then it will return empty array
