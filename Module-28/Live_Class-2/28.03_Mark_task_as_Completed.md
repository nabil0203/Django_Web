# 🎯Mark Task as Completed
- Add a **Completed** button next to the delete button
- When clicked on completed button
    - it will mark the task as completed
    - it will add a line-through to the task title

----------------------------

## 1️⃣ `Task_Viewer.jsx`
- Add a **boolean** property in "Task_Viewer" Component's "addTask()" function
- the default value is false
- When it is true, then it will mark the task as completed
```jsx
function Task_Viewer() {

    // ----------------

    function addTask(event){
        // ------------------------

        const taskObj = {
            id: taskId,
            title: taskTitle,
            description: taskDescription,
            isCompleted: false                              // default value is false
        }
        // ------------------------
    }

    // ----------------
    
}
```
- When a task object is created
    - the default value of `isCompleted` will be `false`

----------------------------

## 2️⃣ `Task_Item.jsx`
- Add **check** mark when task is completed
```jsx
// ------------------------------
    
    <input type="checkbox" checked={task.isCompleted} />
    
// ------------------------------
```

-------------------------------------

## 3️⃣Line-Through when task is completed
### `Task_Item.jsx`
- When the task is completed
    - Add a **line-through** to the **task title**
- **Ternary Operator** is used here to add condition in CSS class -> **[28.04_Ternary_in_CSS.md](28.04_Ternary_in_CSS.md)**

```jsx
// ------------------------------
    
    <div>
        <p className={`font-bold ${task.isCompleted ? 'line-through' : ''}`}> {task.title} </p>

        <p className="font-normal text-sm">{task.description}</p>
    </div>
    
// ------------------------------
```

----------------------------------------------

## 4️⃣Mark Task as Completed
### `Task_Viewer.jsx`
- When the checkbox is checked
    - it will mark the task as completed

```js
function Task_Viewer(){

    // ----------------

    function toggleTaskCompletion(id){

    // find the task with the given id with map

    const updatedTasks = tasks.map((task) => {
      if(task.id === id){
        return {...task, isCompleted: !task.isCompleted}                                  // if the task is completed -> make it uncompleted || if the task is uncompleted -> make it completed
      }

      return task;

    });
    
    setTask(updatedTasks);
    saveTaskToLocalStorage(updatedTasks);

  }

    // ----------------
    // ----------------

    
}

```

-----------------------------------------
