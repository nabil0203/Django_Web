## 3️⃣ Open the Modal
- The update modal needs to be opened when the **edit** button is clicked
### `Task_Item.jsx`
```jsx
// -----------


const [isUpdateModalOpen, setIsUpdateModalOpen] = useState(false);                                      // by default modal is closed


// -----------


 <button onClick={()=>setIsUpdateModalOpen(true)} className="bg-blue-400 hover:bg-blue-500 text-white px-3 py-1 rounded-xl cursor-pointer">                      {/*------ when edit button is clicked, it will open the modal ------*/}
    Edit
</button>




{isUpdateModalOpen ? <ModalUpdateForm closeModal={() => setIsUpdateModalOpen(false)} /> : null}                             {/*   if isUpdateModalOpen is true -> show ModalUpdateForm component */}
```

> Now the Model is opened when the edit button is clicked

## 5️⃣Show Task Data in Modal

### `ModalUpdateForm.jsx`
```jsx
function ModalUpdateForm({ closeModal, task }){

    // -------------------------


    <input defaultValue={task.title} type="text" name="taskTitle" placeholder="Task Title" className="w-full px-3 py-2 border rounded-xl"/>
    <textarea defaultValue={task.description} name="taskDescription" placeholder="Task Description" className="w-full mt-3 px-3 py-2 border rounded-xl"></textarea>


    // -------------------------

}
```
- `defaultValue={task.title}` is used to show the task data in the modal
- `defaultValue={task.description}` is used to show the task data in the modal

> Now the Task data is shown in the modal
