# 📌Modals
- Modal means **Temporary `Pop-up` Window**
- When pops up, the background will be **Blurred** or **Dimmed**

## ▶️Why modal?
- Focus on the task
- No distraction
- Makes the website more interactive


## 📋Modals in `Task Manager` Project
- In this Project, there wil be a button
- When the button is clicked -> **Modal will pop up**
- We can add new tasks in the modal by **Form**
- Then Click on **Save** button
- The tasks will be saved in the **Array**
