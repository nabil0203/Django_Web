# ▶️ React Pdf

## 📍Different Tags in React Pdf

### 1️⃣Document
- Must be the root component
- Container for the entire PDF document
- Can't be child of any other component

----------------------------------------

### 2️⃣Page
- Used to create a page in a PDF document
- Represents single page inside the PDF documents
- A **<Document />** can contain as many pages as you want

----------------------------------------

### 3️⃣View
- Similar to **<div>**
- Used to create a view in a PDF document

--------------------------------------------
--------------------------------------------
--------------------------------------------



## 📍Different Styles in React Pdf
- Styling is done as **Objects**
- 2 ways to add style
    - **1. StyleSheet.create()**
    - **2. Inline style**

---------------------------------

### 1️⃣StyleSheet.create()
-

        flexDirection: 'row',
        backgroundColor: '#E4E4E4',

### 2️⃣Inline style
- Similar to inline css
```js
import React from 'react';
import { Page, Text, View, Document } from '@react-pdf/renderer';

const MyDocument = () => (
  <Document>
    <Page size="A4" style={{ backgroundColor: 'tomato' }}>
      <View style={{ color: 'white', textAlign: 'center', margin: 30 }}>
        <Text>Section #1</Text>
      </View>
    </Page>
  </Document>
);
```
