# 📄React-PDF

- A 3rd party library
- It helps to generate PDF in client-side

----------------------------------

## 🔗Official Website
- https://react-pdf.org/

----------------------------------


## 📦Installation
```bash
npm install @react-pdf/renderer --save
```

---------------------------


## ✅Basic Setup
### 📌`Invoice.jsx`
- Copy the basic code from the official website
```jsx
import { Document, Page, Text, View, StyleSheet } from '@react-pdf/renderer'

// Create styles
const styles = StyleSheet.create({
    page: {
        flexDirection: 'row',
        backgroundColor: '#E4E4E4',
    },
    section: {
        margin: 10,
        padding: 10,
        flexGrow: 1,
    },
});



function Invoice(){
    return(
        <Document>
            <Page size="A4" style={styles.page}>
                <View style={styles.section}>
                    <Text>Section 1</Text>
                </View>
                <View style={styles.section}>
                    <Text>Section 2</Text>
                </View>
            </Page>
        </Document>
    );
}

export default Invoice;
```

---------------------------------------


### 📌`App.jsx`
- Call the Invoice component
```jsx
// -----------------------
import { PDFViewer } from '@react-pdf/renderer'

function App() {
 
  //-------------------------------
  //-------------------------------


  return (
    <>
      
    // ---------------------------------
    // ---------------------------------


      {/* {showPDF ? <Invoice /> : null} */}

      {showPDF ? 
      
      <PDFViewer style={{ width: '700px', height: '600px', margin: '20px' }}>                           {/* PDFViewer component is used to display the PDF */}

}
```
