# Class 8

**Duration:** 90 minutes

## Topics to Discuss:
- Heaps (min/max), Priority Queues
- Hash Tables and Dictionary usage
- Dynamic Programming basics
- Dijkstra’s Algorithm (with heapq)

## Activities:
- Use `heapq` module to create min-heap
- Solve a basic dynamic programming problem (e.g., Fibonacci with memoization)

## Homework:
- Implement a priority queue using heapq
- Solve 2 dynamic programming problems (e.g., climbing stairs, knapsack basics)
