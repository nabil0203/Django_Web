# ▶️Setup

## 1️⃣`App.jsx`
```jsx

import Users from './components/users/Users'
import SingleUser from './components/users/SingleUser'

import { BrowserRouter, Routes, Route } from 'react-router-dom'


function App() {
  return (

    <BrowserRouter>


    <Routes>

      <Route path="/users" element={<Users />} />                             {/* Static Route for all Users */}


      <Route path="/users/:id" element={<SingleUser />} />                    {/* Dynamic Route for single user */}

    </Routes>

    </BrowserRouter>

  )
}

export default App;
```

- `/users` -> All Users Page
- `/users/:id` -> Single User Page

----------------------------------------------------

## 2️⃣`SingleUser.jsx`
```jsx


import { useState } from "react"
import { useParams } from "react-router-dom"



function SingleUser() {


    const [user, setUser] = useState(null)

    const {id} = useParams()                                                                         // get specific user id from URL parameters



    async function GetUserById() {

        const r = await fetch(`https://fake-json-api.mock.beeceptor.com/users/${id}`)                       // fetch user data from API using the id from URL parameters
        const json = await r.json()

        // console.log(json)
        setUser(json)

    }

    return (
        <div>
            <h1>Single User Details</h1>
            


            <button onClick={GetUserById}>Get user by ID</button>

            {user && (
                <div> 
                    {user.name} - {user.email}
                </div>
            )}
        </div>
    )

}

export default SingleUser
```
------------------------------------------

- If you change user id in the url (like -> /users/2)
  - then click on "Get user by ID" button
  - then it will fetch that **specific** user data from API using the id from URL parameters.
  - Then it will display the user data in the browser.

-----------------



### 📌 Important Note

- In URL "/users/:id" 
  - **`:`** tells react router that the segment after it is dynamic
  - **`id`** is the name of the parameter
    - this name should match with the name of the parameter in the `useParams()` hook
