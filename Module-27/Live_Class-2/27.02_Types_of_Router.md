# ▶️Types of Router

### 1️⃣ Browser Router  
- Goes to the Server (backend).
- Refresh full page.
- Slow but reliable.
- The errors are defined in the server so that it can handled easily
- Good for dynamic website.



### 2️⃣ Hash Router
- Goes to the Client (frontend).
- No refresh full page.
- Fast but not reliable.
- The errors are defined in the client.
- Good for static website.
