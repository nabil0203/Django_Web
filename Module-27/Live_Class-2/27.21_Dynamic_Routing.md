# 🚀Dynamic Routing

- It is used to route components based on dynamic URLs
- A route that includes a variable segment (often called a "URL parameter" or "dynamic segment")
    - Allowing a single component to handle many different paths (like -> /user/1, /user/2, etc.)

--------------------------------------------------

### 📝Problem Scenario

- We have a Student management system that needs to display each student's information.
- Each student has a unique ID
- We want to create a page for each student that shows their specific details.
- We would need to manually create a lot of routes for each student:

```jsx
<Route path="/student/1" element={<Student1 />} />
<Route path="/student/2" element={<Student2 />} />
<Route path="/student/3" element={<Student3 />} />
```

- This approach is not scalable
- This becomes very difficult to manage as the number of students grows.


----------------------------

## 💡In this situation we can use **`Dynamic routing`**
- Whenever a new student is added
    - automatically **`routing`** will be created
- We don't need to create route manually.

---------------------------

## 💡`useParams()` hook
- It is used to get the dynamic route parameters
- It returns an object of key/value pairs of the dynamic segments of the URL
