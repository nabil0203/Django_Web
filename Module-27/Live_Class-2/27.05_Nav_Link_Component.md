# 🔗Nav Link

- Used to create links to **`go`** to different pages in a website.
- Uses immediately invoked function expression `({ isActive }) => ...` in className or style.
- The active link will be highlighted.
- Can pass parameter in className.
- Can add tailwind in className or style.

## ▶️Setup

### 1️⃣ Install
- Inside the project folder.
```
npm install react-router-dom
```

------------------------------


### 2️⃣ App.jsx
```jsx
import './App.css'
import Home from './components/home/Home'
import About from './components/about/About'

import { BrowserRouter, Routes, Route, NavLink } from 'react-router-dom'                                     // import NavLink


function App() {
  return (

    <BrowserRouter>

    <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
    </Routes>


    <nav>


      <NavLink to="/" className={({ isActive }) => (isActive ? 'active-link' : 'inactive-link')}>                                               {/* ----- Linked to home page */}
        Go to home page
      </NavLink>



      <br />


      <NavLink to="/about" className={({ isActive }) => (isActive ? 'active-link' : 'inactive-link')}>                                          {/* ----- Linked to about page */}
        Go to about page
      </NavLink>

    </nav>


    </BrowserRouter>

  )
}

export default App
```

### Explain
`({ isActive }) => (isActive ? 'active-link' : 'inactive-link')`
- `isActive` is a boolean value.
- The immediately invoked function expression `({ isActive }) => ...` is a function that is called immediately when the component is rendered.
- When the link is active, `isActive` is true and it will have the class 'active-link'.
- When the link is inactive, `isActive` is false and it will have the class 'inactive-link'.
- The class 'active-link' and 'inactive-link' are defined in App.css.
----------------------------------------
## ⚠️**If I want to add tailwind styles in className or style.**

```jsx

    <NavLink to="/" className={({ isActive }) => (isActive ? 'text-blue-500' : 'text-red-500')}>
      Go to home page
    </NavLink>

```
**Output:**
- When the link is active -> text-blue-500.
- When the link is inactive -> text-red-500.
