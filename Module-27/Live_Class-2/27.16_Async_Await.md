# ✅Async Await

- When API is called
    - the data is coming form the server
    - which takes time
- At this time
    - the Browser freezes
    - The user can't do anything
- When data comes
    - Then the Browser unfreeze
    - And show the data

----------------------------------------------------

- To provide this time we use **`Async/Await`**
    - `Async` is for **Function**
    - `Await` is for **waiting** (for response)
                                        

------------------------

## 📝Basic Structure of `Async/Await`

```jsx


function Users() {
    
    async function fetchUsers(){
        
        const r = await fetch('url')                 // Waiting for response 
        const json = await r.json()                  // Waiting for JSON format

    }

}
```
- `url` -> endpoint of an API
- `r` -> response from the server
- `json` -> JSON format of the response
