# Link Page
- **`NavLink`** is more used than `Link`.
- Check `27.05_Nav_Link_Component`


--------------------------------------------------


## ▶️Setup

### 1️⃣ Install
- Inside the project folder.
```
npm install react-router-dom
```

------------------------------


### 2️⃣ App.jsx
```jsx
import './App.css'
import Home from './components/home/Home'
import About from './components/about/About'

import { BrowserRouter, Routes, Route, Link } from 'react-router-dom'                                     // import


function App() {
  return (

    <BrowserRouter>


    <Routes>

        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />

    </Routes>



    <nav>

      <Link to="/">Go to home page</Link>                                             {/* ----- Linked to home page */}
      <br />
      <Link to="/about">Go to about page</Link>                                          {/* ----- Linked to about page */}

    </nav>


    </BrowserRouter>

  )
}

export default App
```
