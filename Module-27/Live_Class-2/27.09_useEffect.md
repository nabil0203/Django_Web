# 🪝useEffect Hook

- If something changes in one part of the web page, it can trigger a change anywhere else on the page.
- So, whenever we will change anything in our web page, it will trigger a change anywhere else on the page.
- `When a component depends on many things, useEffect is used`

-----------------------------------

## ▶️Example:
- A FB message pops up and the tab name changes
- Make an error while writing something in text area, a pop up message shows up


--------------------------------------------

## ▶️Structure
```jsx
import { useEffect } from "react";

useEffect(() => {
   // effect code

}, [dependency array]);
```

---------------------------------------------------


## 💠Types of useEffect

### 1️⃣ useEffect(fn) → every render
- Only function no array
- Run every render
### 2️⃣ useEffect(fn,[]) → once
- Array will be empty
- Run once
### 3️⃣ useEffect(fn,[x]) → when x changes
- x is dependency array
- Run when x changes


-----------------------------------------------------


## ⚠️Common Mistakes:
- Wrong dependencies → stale data
- No cleanup for timers
- Fetch in render (avoid)
