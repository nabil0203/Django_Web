# 🧭 Navigation

- It is used to navigate between different 
    - routes
    - components
    - pages    

## 📋 Scenario

- In the all `Users` page we have all Users data
- Each user will have a button
    - that will navigate to the `SingleUser` page
    - using the dynamic route
    - using the user's id

------------------------------------------
