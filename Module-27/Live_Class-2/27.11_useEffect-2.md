# 2️⃣Type-2: useEffect(fn,[])

- Only run once at the start of the component rendering
- Dependency array is empty
- Empty array means → **`once`**


----------------------------------------

## 📌Home.jsx
```jsx
import { useEffect, useState } from "react"


function Home() {

  const [count, setCount] = useState(0)                     // count -> useState variable



  useEffect(() => {                                              // useEffect hook 
    document.title = `Tab Count: ${count}`                       // tab title will be updated only once
  }, [])                                                         // dependency array -> empty



  return (
    <div>

      <h1>This is Home page</h1>


      <button onClick={() => setCount(count+1)}> Count: {count}</button>                             {/* onClick  -> setCount function -> update count state variable */}       


    </div>
  )
}


export default Home
```
