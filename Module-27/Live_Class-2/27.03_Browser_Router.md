# 📌Browser Router

## ▶️Setup

### 1️⃣ Install
- Inside the project folder.
```
npm install react-router-dom
```

------------------------------


### 2️⃣ App.jsx
```jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom'                    // import BrowserRouter, Routes and Route


import './App.css'
import Home from './components/home/Home'                                          // import Home component
import About from './components/about/About'                                       // import About component



function App() {
  return (

    <BrowserRouter>                                                     {/*--- 1. BrowserRouter is a component -> used to route all the components in the website.*/}

      <Routes>                                                          {/*---- 2. Routes is a component -> used to route all the components in the website.*/}

        <Route path="/" element={<Home />} />                           {/*---- 3. Route is a component -> used to route the components in the website.*/}
        <Route path="/about" element={<About />} />
        
      </Routes>

    </BrowserRouter>

  )
}

export default App;
```
- import BrowserRouter to route all the components in the website.
- import Routes to route all the components in the website.
- import Route to route the components in the website.
- import components name(Home, About) from components folder.
----------------------------------
- `path` is the URL/link (address) of the component.
- `element` is the component to be rendered/opened.
