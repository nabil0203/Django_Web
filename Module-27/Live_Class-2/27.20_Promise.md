# 🤝Promise
### Promise can be used but not recommended 🚫🚫

------------------------------------------



## 🎯Why Promise is not recommended?
- It is not that much readable as `async/await`
- It is older way of handling asynchronous operations
- It is less concise and harder to understand

## 💡Why Async/Await is recommended?    
- Because it is more readable and updated
- It is newer way of handling asynchronous operations 
- It is more concise and easier to understand




---------------------------------------------------



## 📝Basic Structure of `Promise`

```jsx
function Users() {

    function fetchUsers() {
    
    fetch(URL)                                                    // fetch data from URL
        .then(r => r.json())                                     // Converting response to JSON format
        . then(setUsers)                                         // Setting data in state
    }

}
```

- `fetch(url)` -> fetch data from URL
    - `url` -> endpoint of an API
- `.then(r => r.json())` -> Converting response to JSON format
    - `r` -> response from the server
    - `.json()` -> convert response to JSON format
- `.then(setUsers)` -> Setting data in state
    - `setUsers` -> state hook for setting users data
    - `setUsers(json)` -> Setting data in state
