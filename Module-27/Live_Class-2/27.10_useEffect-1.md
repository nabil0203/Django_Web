# 1️⃣Type-1: useEffect(fn)

- Always run after the component is rendered
- If any state variable or props is updated, useEffect will be called
- No dependency array


------------------------------------------


## 📌Home.jsx
```jsx
import { useEffect, useState } from "react"


function Home() {

  const [count, setCount] = useState(0)                     // count -> useState variable



  useEffect(() => {                                              // useEffect hook 
    document.title = `Tab Count: ${count}`                       // tab count will be updated every time the component is rendered
  })                                                             // no dependency array



  return (
    <div>

      <h1>This is Home page</h1>


      <button onClick={() => setCount(count+1)}> Count: {count}</button>                             {/* onClick  -> setCount function -> update count state variable */}       


    </div>
  )
}


export default Home
```
-----------------------------------------------------

- Whenever count is updated, document title will be updated with the new count value
