# 3️⃣Type-3: useEffect(fn, [x])

- Run only when the dependency array changes
- 



---------------------------------------------------------------

## 📌Home.jsx
```jsx
import { Link } from "react-router-dom"
import { useEffect, useState } from "react"


function Home() {

  const [count, setCount] = useState(0)                     // count -> useState variable



  useEffect(() => {                                              // useEffect hook 
    document.title = `Tab Count: ${count}`                       // Whenever "count" state variable is updated, document title will be updated with the new count value
  }, [count])                                                    // count -> dependency array -> useEffect will be called whenever count state variable is updated



  return (
    <div>

      <h1>This is Home page</h1>


      <button onClick={() => setCount(count+1)}> Count: {count}</button>                             {/* onClick  -> setCount function -> update count state variable */}       


    </div>
  )
}


export default Home
```

-------------------------------------------

- In Home.jsx
- count -> useState variable
- setCount -> useState function

-------------------------------------------

## 📌useEffect(fn,[])

- count -> dependency array
- useEffect will be called whenever count state variable is updated
- document.title -> Whenever count state variable is updated, document title will be updated with the new count value
