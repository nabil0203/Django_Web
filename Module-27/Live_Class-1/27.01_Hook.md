# 🪝Hooks

- Re-renders component
- Refresh value of the component
- This value is called **State**
- This state will not be lost when component re-renders

-----

## 📌Example without Hook

### 1️⃣ App.jsx
```jsx
import './App.css'
import Change from './Change'

function App() {

  return (
    <>
    <div>

      <h1>Hooks and States</h1>
      
      <Change />                                // component

    </div>
    </>
  )
}

export default App
```

### 2️⃣ Change.jsx
```jsx
function Change() {
    
    let x = 10;

    function increment() {
        x = x + 1;
        console.log(x);                          //👈used to verify that value of x changes in console
    }

    return (
        <div>
            <p>Increment on click</p>

            <p>{x}</p>

            <button onClick={increment}>Click Me</button>               //👈used to call increment function on click
        </div>
    )
}

export default Change
```


------------------------------------


###  👆The `Onclick {increment}` function 
- Should change the value of **`x`** on click of button
- But the value of **`x`** is changing
    - Only In console ✅
    - But **not updating in UI** ❌
--------

### 👇Why value is not updating in UI?

- The **value** of x is not updating in UI
    - Because it's a **Static Page**

------------------------

### ❔How to **change the UI**?

- We need to take some additional steps to **change the UI**
- Steps:
    - **Re-render** the component to update the UI
    - To re-render the component we need to use **Hooks**
