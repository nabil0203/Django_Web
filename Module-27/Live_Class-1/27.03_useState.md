# 📌useState Hook
- UI change
- Re-renders the whole component

-------------------


## ▶️ **`useState()`**
- useState() always returns an array of two values
    - First value is name of the **`variable`**
    - Second value is the **`function`** to change the value of the variable

## 🔑Key Points
- While changing the useState value by **`setX()`** function
    - the whole component is re-rendered
- Therefore the UI changes.



-----------------------


### ▶️Syntax:
```jsx
import { useState } from 'react';

const [value, setValue] = useState(initialValue);
```
- `value` -> variable name
- `setValue` -> function name
- `initialValue` -> initial value

## 2️⃣Change.jsx
```jsx
import { useState } from 'react';

function Change() {

   const [x, setX] = useState(0);                      // useState is a hook 
                                                        //"x" is the variable and "setX" is the function to change the value of x; initial value of x    0; 

    function increment() {                                 // function to increment the value of x by 1 each time
        setX(x + 1);
    }

    function decrement() {                                 // function to decrement the value of x by 1 each time
        setX(x - 1);
    }

    return (
        <div>
            <p>Increment/Decrement on click</p>

            <p>{x}</p>

            <button onClick={increment}>Add</button>
            <button onClick={decrement}>Subtract</button>
        </div>
    )
}

export default Change
```
