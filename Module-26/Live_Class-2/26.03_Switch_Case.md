# 👆Switch case



### ▶️`App.jsx`
```jsx

function App() {

  const number = 10;


  switch (number) {


    case 10:
      return (
        <h1> The number is TEN </h1>
      )

    case 30:
      return (
        <h1> The number is Thirty </h1>
      )

    case 40:
      return (
        <h1> The number is Forty </h1>
      )

  }


}
```
