# 🍹Tailwind in React

### 🔗Official Documentation ---> [Click Here](https://tailwindcss.com/docs/installation/using-vite)


------------------------------


### ▶️Prerequisite
- Create your React project with Vite
```
npm create vite@latest
``` 

## 1️⃣Install Tailwind CSS 
```bash
npm install tailwindcss @tailwindcss/vite
``` 


---------------------------------


## 2️⃣`vite.config.js`
- In this file
    - Import taiwindcss
    - add tailwind css plugin

```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'                     // 👈import

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),                                             // 👈plugin

  ],
})
```




----------------------------------------



## 3️⃣`index.css`
- Add the Tailwind directives to the main CSS file
```css
@import "tailwindcss";
```




----------------------------------------



## 4️⃣Run
```
npm run dev
```
