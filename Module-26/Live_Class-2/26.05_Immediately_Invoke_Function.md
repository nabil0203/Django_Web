# 📍Immediately Invoke Function

- Normal Functions need to be called to perform
- ***Immediately Invoke Function*** doesn't need to be called
- Runs immediately after it is defined.
- You don’t need to call it separately.
- Not used that much


-----------------------------


## ▶️Syntax
- The function is wrapped in parentheses → `(function() {})`
- The final `()` executes it immediately.

```js
(function () {
    
  console.log("App Started...");
  
})()
```
