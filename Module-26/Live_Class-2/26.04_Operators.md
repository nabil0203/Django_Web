# ▶️Operators

- **`&&`** Logical AND
- **`||`** Logical OR
- **`!=`** Logical NOT EQUAL


### ⚠️Important
- In JS we have `==` and `===` 
- `==` ---> only checks the Value
- `===` --> Checks Value and Data type

```jsx
const age = 10              // number
const age2 = '10'           // string

age == age2                 // Correct✅ [same value]
age === age2                // Wrong❎  [same value but not same data type]
```
