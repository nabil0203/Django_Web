# 🚨Conditional Rendering

- We have a condition
- Then we are rendering based on that condition

```jsx
function App() {

  // const isUserLoggedIn = true;                            // 👈condition--> true/false
  const isUserLoggedIn = false;

  return (
    <>
      <div>
        <h1>This is Nabil Ahmed</h1>


        {isUserLoggedIn ? <h3>Welcome to this site </h3> : <p> Please Login </p> }                 // 👈 Ternary operator based on the condition

      </div>
    </>
  )
  
}

export default App
```
