# 📍Map

### 🔁Works same as Loop

```jsx
function Map(){

    const my_projects = ['Taskify', 'ShopNest', 'EduStack', 'CarHub'];                      // 👈 list

    return(

        <div>
        {
            my_projects.map((project, index) => {
                    return <div>{project}</div>                                         // returning one by one
                })
        }
        </div>

    )

}

export default Map
```
---------------------

- List ---> **my_projects**
- Variables ---> **project** and **index**
- project
    - captures each objects of the list
- index
    - stores the index of the objects each time
