# ▶️Context Provider
- Some data are needed in all/different components. 
    - So we have to share these data between components.
    - In this case `Context Provider` is used

----------------------------------------
- Similar to `Context Processor` in Django
------------------------------

### Example:
- Login
- Register
- Logout
- Continuously check if the user is logged in/registered or not
- In every Page this authentication is needed
