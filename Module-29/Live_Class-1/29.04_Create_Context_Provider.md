# ▶️Create Context Provider
- At first we need create a Context provider
- After that we have to add the login/logout/register functionality inside the provider

-------------------------

# 📌Steps

## 1️⃣ `src/context/AuthProvider.jsx`
- We have to create a file `AuthProvider.jsx`
- This file will be in `context` folder
-------------------------------------------

## 2️⃣ Use `createContext()`
- To create the **context** we need to use `createContext()`
- This function is coming from `react`

### `AuthProvider.jsx`
```jsx
import { createContext } from "react";

const AuthContext = createContext();
```
- `AuthContext` helps to pass the data in different places

----------------------------------------------

## 3️⃣ Create a custom Hook
- We create a function `useAuth()`
- Inside that function we use `useContext()` and pass `AuthContext` to it
- By this way, we don't need to import **useContext()** every time
- We can just import **useAuth()**
- We need this because our **AuthContext** will be used by other components

### `AuthProvider.jsx`
```jsx
export const useAuth = () => {
    const context = useContext(AuthContext);
    if (!context) {
        throw new Error("useAuth must be used within an AuthProvider");
    }
    return context;
}
```

--------------------------------------------------

## 4️⃣Create a Provider
- We need a provider to use the **context**
- Provider is like a tag
- This provider will share the data with all child components

### `AuthProvider.jsx`
```jsx
const AuthProvider = ({ children }) => {
    return (
        <AuthContext.Provider value={{}}>
            {children}
        </AuthContext.Provider>
    );

```

# 📌Full `AuthProvider.jsx`

```jsx
import { createContext, useContext } from "react";

const AuthContext = createContext();


export const useAuth = () => {
    const context = React.useContext(AuthContext);
    if (!context) {
        throw new Error("useAuth must be used within an AuthProvider");
    }
    return context;
};



const AuthProvider = ({ children }) => {
    return (
        <AuthContext.Provider value={{}}>
            {children}
        </AuthContext.Provider>
    );
}


export default AuthProvider;
```
