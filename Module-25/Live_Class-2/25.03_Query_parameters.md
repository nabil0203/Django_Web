## ▶️Query Parameters🌟


### 1️⃣What Are Query Parameters?
- Query parameters are values added to a URL after a ? to send extra information to the server.
- They are
    - Optional
    - Key-value pairs
    - Mostly used in GET requests
- Optional key-value pairs added to a URL to filter, search, or modify returned data — mostly used in GET requests.
```
/api/courses/?category=Web&search=django&page=2
```
- Everything after **`?`** is the query string.


---------------------------------------


### 2️⃣Structure of Query Parameters
```bash
?key=value&key=value&key=value
```

---------------------------------------


### 3️⃣ Why We Use Query Parameters
- 🔍 Filtering
- 🔎 Searching
- 📄 Pagination
- ↕ Sorting
- 🎯 Optional customization


---------------------------------------



### 4️⃣Real Backend Example
- **views.py**
```py
category = request.query_params.get('category')                      # Query Parameters
search = request.query_params.get('search')                          # Query Parameters
```

### 5️⃣So if user visits:
```bash
/api/courses/?category=Web&search=django
```
- Then you filter database based on these values.
    - category = "Web"
    - search = "django"
