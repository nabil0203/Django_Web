# 📃 Custom User Model


## 🔎 What is Happening Here?
- Instead of using Django’s default `User` model directly, we inherit it from `AbstractUser`
- So we can **add extra custom fields** while keeping all built-in authentication features.


# 📌Steps

### 1️⃣`models.py` - users_app

```python
from django.db import models

from django.contrib.auth.models import AbstractUser



class User(AbstractUser):                                           # keeping the name 'User', can change it

    class User(AbstractUser):                                        
    role = models.CharField(max_length=100)                       # extra with the User class
    mobile_no = models.CharField(max_length=100)                  # extra with the User class

```


-------------------




### 1️⃣`settings.py`
- Add the AUTH_USER_MODEL setting to point to your new model
```py
AUTH_USER_MODEL = 'users_app.User'                                      #'users_app' is the app of this project
```
