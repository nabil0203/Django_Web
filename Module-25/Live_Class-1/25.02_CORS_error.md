# 📐Cross-Origin Resource Sharing (CORS)

- It’s basically the browser saying: “Hey, this website is trying to talk to another website, and I’m not sure that’s allowed.”


## What is a CORS error❔
- Let's say, we are building a full stack project
- A CORS error happens when:
    - Frontend tries to call a backend API
    - The backend does not allow, because it does not know where the request is coming from
- Browser says:
    - “This request is blocked by CORS policy”


-----------------

## 🔥 Why browsers block it?

- Security reasons:
    - To prevent malicious websites from reading private data
    - Protect users from CSRF-like attacks

- Without CORS, any random site could:
    - Call your API
    - Read sensitive data using your logged-in session

# 🧠How it’s fixed

## 1️⃣Install the package:
- Install
```bash
pip install django-cors-headers
```


## 2️⃣`settings.py`
- Add to **INSTALLED_APPS**
```py
INSTALLED_APPS = [
    .......,

    'corsheaders',

    .......,
]
```



## 3️⃣`settings.py`
- Add to **MIDDLEWARE**
```py
MIDDLEWARE = [

    ..........,

    'corsheaders.middleware.CorsMiddleware',         # Add this
    
    ..........,
]

```




## 4️⃣`settings.py`
- Add
```py
CORS_ALLOWED_ALL_ORIGINS = True
```
- This means all the origins are allowed
- This is not good practice


------------

- This is how it should be done
```py
CORS_ALLOWED_ORIGINS = [
    "http://localhost:3000",
    "http://127.0.0.1:3000",
    "https://yourdomain.com",
]
```
